कॉलोनी मित्र · अभिराज डिजिटल
==============================

1. "सेटअप-गाइड.html" को ब्राउज़र में खोलें। उसमें शुरू से आख़िर तक हर स्टेप हिंदी में लिखा है।

2. फ़ोल्डर:
   website/colony-mitra/      → यह पूरा फ़ोल्डर अपनी Vercel वेबसाइट (GitHub) में डालें
       index.html              → डाउनलोड / जानकारी पेज
       demo.html               → बिना लॉगिन चलने वाला डेमो (कमेटी: 99999 00001, निवासी: 99999 00002, OTP 123456)
       app/                    → असली ऐप
       app/config.js           → सिर्फ़ यही फ़ाइल भरनी है (Supabase URL + key)
   supabase/schema.sql         → Supabase SQL Editor में एक बार चलाएँ
   supabase/functions/send-whatsapp/index.ts → अपने आप WhatsApp भेजने के लिए (वैकल्पिक)
   supabase/whatsapp-templates.txt           → Meta में बनाने वाले टेम्पलेट

3. ऐप में क्या है:
   OTP लॉगिन (ईमेल / SMS / WhatsApp) · कई कॉलोनियाँ (हर कॉलोनी का डेटा अलग)
   घर व निवासी · पार्किंग · CCTV · मेंटेनेंस (1–10 तारीख, लेट फीस, रसीद)
   UPI QR से ऑनलाइन भुगतान + कमेटी की पुष्टि · शिकायत/सुझाव · हिसाब-किताब (रोकड़ बही)
   पोल/वोटिंग · फोटो गैलरी · सेवाएँ · कमेटी सदस्य · एडमिन पैनल · ऐप मालिक पैनल
   फ़ोन में इंस्टॉल (PWA) · APK बनाने का तरीका (गाइड स्टेप 8)
