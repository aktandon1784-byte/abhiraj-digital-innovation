शुरू से आख़िर तक, हर स्टेप हिंदी में। पहली बार में लगभग 1–2 घंटे लगेंगे।

साफ़ बात: ऐप का पूरा कोड, डेटाबेस और सुरक्षा नियम तैयार और जाँचे हुए हैं। OTP भेजने (Twilio) और WhatsApp भेजने (Meta) वाली कंपनियाँ अपनी चाबियाँ (keys) सिर्फ़ खाते के मालिक को देती हैं। इसलिए नीचे के अकाउंट आपको अपने नाम से बनाने होंगे और उनकी चाबियाँ भरनी होंगी। इन वेबसाइटों के बटन और मेन्यू के नाम समय के साथ थोड़े बदल सकते हैं। अगर कहीं अटकें, तो उसी स्टेप का स्क्रीनशॉट Claude को भेज दें।

1Supabase अकाउंट और प्रोजेक्ट

  1. supabase.com खोलें → Start your project → GitHub से साइन-इन करें।
  2. New project दबाएँ। Name: colony-mitra। Database password: कोई मज़बूत पासवर्ड बनाकर कहीं लिख लें।
  3. Region में South Asia (Mumbai) चुनें, ताकि ऐप तेज़ चले। Plan: Free।
  4. Create new project दबाएँ और 1–2 मिनट रुकें।

2डेटाबेस बनाना

  1. बाएँ मेन्यू में SQL Editor खोलें → New query।
  2. supabase/schema.sql फ़ाइल को Notepad में खोलें, पूरा कॉपी करें और यहाँ चिपका दें।
  3. Run दबाएँ। नीचे Success लिखा आना चाहिए। (इसे दोबारा चलाने से कोई नुकसान नहीं होता।)
इससे बन जाते हैं: कॉलोनियाँ, सदस्य, सारा डेटा, फोटो रखने की जगह और सुरक्षा नियम। जैसे: निवासी हिसाब नहीं बदल सकता, दूसरे का वोट नहीं डाल सकता, बाहर का व्यक्ति कुछ नहीं देख सकता। ये सारे नियम जाँचे जा चुके हैं।

3config.js भरना

  1. Supabase में ऊपर Connect बटन या Project Settings → API खोलें।
  2. Project URL कॉपी करें (जैसे https://abcd1234.supabase.co)।
  3. anon public key या Publishable key कॉपी करें। service_role / secret key कभी नहीं डालनी।
  4. public/colony-mitra/app/config.js खोलें और भरें:
SUPABASE_URL: "https://abcd1234.supabase.co",
SUPABASE_ANON_KEY: "eyJhbGciOi....  या  sb_publishable_....",
SUPPORT_WHATSAPP: "919876543210",   // आपका नंबर
LOGIN_METHODS: ["email"],            // शुरू में सिर्फ़ ईमेल (मुफ़्त); स्टेप 5 के बाद "phone_sms" जोड़ें

4ईमेल OTP चालू करना (मुफ़्त)

  1. Supabase → Authentication → Sign In / Providers → Email चालू (Enabled) रखें।
  2. Authentication → Email Templates खोलें। Magic Link और Confirm signup दोनों टेम्पलेट में संदेश बदलकर यह लिखें: 
    <h2>कॉलोनी मित्र</h2>
<p>आपका लॉगिन OTP है: <b style="font-size:24px">{{ .Token }}</b></p>
<p>यह OTP किसी को न बताएँ।</p>
  3. ज़रूरी: Supabase की मुफ़्त ईमेल सेवा घंटे में बहुत कम ईमेल भेजती है। इसलिए Authentication → Emails → SMTP Settings में अपना SMTP डालें। जैसे Brevo (मुफ़्त प्लान में रोज़ लगभग 300 ईमेल), या Gmail का App Password।
  4. Authentication → URL Configuration में Site URL डालें: https://abhiraj-digital-innovation.vercel.app/colony-mitra/app/index.html

5मोबाइल SMS / WhatsApp OTP

  1. twilio.com पर अकाउंट बनाएँ और थोड़ा बैलेंस डालें।
  2. Twilio Console → Verify → Services → Create new → नाम Colony Mitra रखें। Service SID (VA… से शुरू) कॉपी करें। Console के होम पेज से Account SID और Auth Token भी कॉपी करें।
  3. Supabase → Authentication → Sign In / Providers → Phone → Enable करें → SMS provider में Twilio Verify चुनें → तीनों चीज़ें भरकर Save करें।
  4. WhatsApp OTP: Twilio Verify सर्विस में WhatsApp channel चालू करें। Twilio इसके लिए अपना WhatsApp sender जोड़ने को कह सकता है, उनकी शर्तें पूरी करें।
  5. config.js में LOGIN_METHODS: ["phone_sms", "phone_whatsapp", "email"] करें। जो चालू नहीं किया, उसे हटा दें।
भारत में SMS के लिए DLT नियम लागू होते हैं। Twilio Verify OTP संदेशों के लिए ये नियम ख़ुद संभालने का दावा करता है, फिर भी Twilio की वेबसाइट पर भारत के नियमों की ताज़ा जानकारी ज़रूर देख लें। हर OTP का खर्च Twilio की रेट-लिस्ट के हिसाब से लगेगा।

6वेबसाइट पर अपलोड

  1. github.com पर अपनी वेबसाइट abhiraj-digital-innovation की repository खोलें।
  2. फ़ोल्डर चुनें:
    • अगर उसमें public फ़ोल्डर है (React, Next.js या Vite वाली साइट), तो उसे खोलें।
    • अगर सिर्फ़ index.html जैसी फ़ाइलें हैं, तो सबसे ऊपर वाले मुख्य फ़ोल्डर में ही रहें।
  3. Add file → Upload files → website/colony-mitra पूरा फ़ोल्डर खींचकर डालें → Commit changes।
  4. Vercel 1–2 मिनट में अपने आप वेबसाइट अपडेट कर देगा। अब ये पते खुलेंगे: 
    डाउनलोड पेज:  https://abhiraj-digital-innovation.vercel.app/colony-mitra

7पहली बार ऐप चलाना

  1. असली ऐप का पता खोलें → अपने नंबर या ईमेल से OTP डालकर लॉगिन करें।
  2. स्क्रीन पर "नंबर किसी कॉलोनी में नहीं जुड़ा" आएगा। नीचे "मैं इस ऐप का मालिक हूँ" दबाएँ। यह काम सबसे पहले आप ही करें, क्योंकि जो पहले दबाएगा वही ऐप का मालिक बनेगा।
  3. 👑 ऐप मालिक पैनल खुलेगा → नई कॉलोनी जोड़ें: नाम "लक्ष्मण विहार", और अध्यक्ष या सचिव का नाम व मोबाइल नंबर।
  4. खोलें दबाएँ → एडमिन → सेटिंग्स में ये भरें: मेंटेनेंस की रकम, आख़िरी तारीख (10), लेट फीस, कॉलोनी फंड का UPI ID, और संपर्क नंबर।
  5. घर व निवासी में सारे घर जोड़ें (मालिक और किराएदार के नंबर के साथ)।
  6. एडमिन → लॉगिन वाले सदस्य → "घरों के नंबर से सबको जोड़ें" दबाएँ। इससे सारे मालिक और किराएदार एक बार में निवासी बन जाएँगे। कमेटी वालों की भूमिका "👑 एडमिन" कर दें।
  7. कॉलोनी के WhatsApp ग्रुप में ऐप का लिंक भेज दें। लोग अपने नंबर से OTP डालकर लॉगिन करेंगे।
भुगतान कैसे चलेगा:
  1. निवासी "💳 अभी जमा करें" दबाता है, UPI QR स्कैन करता है या "UPI ऐप से भरें" बटन से पैसे भेजता है।
  2. फिर UTR नंबर लिखकर सूचना भेजता है।
  3. कमेटी को "🔔 भुगतान की पुष्टि बाकी" दिखता है। बैंक में पैसा देखकर ✓ पुष्टि दबाते ही रसीद बन जाती है।
पैसा सीधे कॉलोनी के खाते में जाता है और बीच में कोई फीस नहीं कटती।

8एंड्रॉयड APK बनाना (मुफ़्त)

  1. pwabuilder.com खोलें → असली ऐप का पता डालें (…/colony-mitra/app/index.html) → Start।
  2. Package for stores → Android → Generate → zip डाउनलोड करें।
  3. zip में मिलेंगे:
    • .apk फ़ाइल: फ़ोन में इंस्टॉल करने के लिए
    • .aab फ़ाइल: Play Store के लिए
    • signing.keystore: इसे बहुत संभालकर रखें, अगले अपडेट के लिए यही चाहिए होगी
  4. .apk का नाम बदलकर colony-mitra.apk करें और GitHub में colony-mitra फ़ोल्डर में अपलोड करें।
  5. colony-mitra/index.html में नीचे APK_URL: "colony-mitra.apk" करें। इससे "Download APK" बटन चालू हो जाएगा।
  6. zip में assetlinks.json भी होगी। उसे अपनी साइट में .well-known/assetlinks.json पर डालें (Next.js में public/.well-known/)। इससे APK बिना ब्राउज़र-पट्टी के, पूरी स्क्रीन पर खुलेगा।
  7. Play Store पर डालना हो तो Google Play Console अकाउंट बनाएँ (लगभग $25, एक बार) और .aab फ़ाइल अपलोड करें।

9अपने आप WhatsApp संदेश (वैकल्पिक)

ऐप का "WhatsApp पर भेजें" बटन बिना किसी सेटअप के, मुफ़्त चलता है: WhatsApp खुलता है और भेजने वाला ख़ुद "Send" दबाता है। अपने आप भेजने के लिए:

  1. developers.facebook.com → My Apps → Create App → WhatsApp जोड़ें। Business verification पूरा करें।
  2. WhatsApp → API Setup से Phone number ID और एक Permanent access token (System User token) लें।
  3. supabase/whatsapp-templates.txt वाले 2 टेम्पलेट बनाएँ और उनके मंज़ूर (Approved) होने का इंतज़ार करें।
  4. Supabase → Edge Functions → Deploy a new function → Via Editor → नाम send-whatsapp रखें → supabase/functions/send-whatsapp/index.ts का पूरा कोड चिपकाएँ → Deploy दबाएँ।
  5. Edge Functions → Secrets में डालें: WA_TOKEN, WA_PHONE_ID, और WA_LANG = hi।
  6. config.js में WHATSAPP_API: true करें। अब रसीद और रिमाइंडर में "🤖 अपने आप WhatsApp भेजें" बटन आ जाएगा।

OTP नहीं आ रहा

  • ईमेल: Spam फ़ोल्डर देखें, SMTP सेटिंग जाँचें (स्टेप 4.3), और टेम्पलेट में {{ .Token }} लिखा है या नहीं देखें।
  • SMS: Twilio में बैलेंस है या नहीं देखें, और Supabase Phone provider में तीनों key सही हैं या नहीं।
